Services

다섯 가지를 한 번에 설치합니다

필요한 항목만 골라 도입할 수도 있습니다. 업체 양식과 거래처에 맞춰 설정합니다.

01

매일 아침 메일 자동 분류

밤사이 들어온 메일을 발주·견적 요청·세금계산서·클레임 등으로 나누고, 급한 것부터 정리해 휴대폰으로 보고합니다.

  • 업체가 정한 분류 기준과 거래처 목록 반영
  • 첨부파일(발주서·도면·계산서) 자동 저장
  • 답장이 필요한 메일만 따로 표시
02

견적서·작업지시서·발주서 자동 작성과 발송

메일 속 품목·수량·납기를 읽어 우리 회사 양식으로 문서를 만들고, 확인 한 번으로 거래처에 메일을 보냅니다.

  • 기존 엑셀·한글 양식 그대로 사용
  • 단가표 기준 금액 자동 계산
  • 발송 전 담당자 확인 단계 유지
03

업체 맞춤 발주·주문·매출·매입 현황판

별도 회계 프로그램(예: 얼마에요) 없이도 거래처별 발주·주문·매출·매입을 한 화면에서 봅니다.

  • 업체가 보는 항목·거래처 구분대로 설계
  • 메일·문서 데이터가 자동으로 쌓임
  • PC·휴대폰에서 확인
04

업체 전용 에이전트 설치 + 기본 AI 교육

우리 회사만 쓰는 AI 에이전트를 설치하고, 직원들이 말로 일을 시키는 방법을 현장에서 가르칩니다.

  • 업체 전용 계정·메신저 봇 연결
  • 대표·사무직 대상 기본 AI 활용 교육
  • 설치 후 운영 문의 대응
05

전용 PC와 모니터 제공

에이전트가 24시간 일할 전용 PC를 준비해 설치까지 마칩니다. 맥미니 또는 윈도우 미니PC 중 업체 환경에 맞춰 고릅니다.

  • 맥미니 / 윈도우 미니PC + 모니터
  • 기존 공유 폴더·프린터 연결
  • 항상 켜져 있도록 전원·절전 설정
※ 장비 비용은 견적과 별도로 실비 청구합니다

Process

도입은 이렇게 진행됩니다

STEP 1

상담

현재 메일·문서·관리 방식과 원하는 자동화 범위를 듣습니다.

STEP 2

현장 진단

공장을 방문해 PC·네트워크·양식·거래처 구조를 확인하고 견적을 드립니다.

STEP 3

설치·연동

전용 PC에 에이전트를 설치하고 메일·양식·공유 폴더를 연결합니다.

STEP 4

교육

대표와 사무 담당자에게 사용법과 기본 AI 활용법을 교육합니다.

STEP 5

운영 지원

실제 업무에 쓰면서 나오는 수정 요청을 반영합니다.

Reference

이미 공장에서 돌아가고 있습니다

포장재 제조공장 한 곳에 사무 PC 여러 대와 공유 폴더, 메신저 보고까지 연결해 실제 운영 중입니다. 같은 구성을 업체 상황에 맞춰 설치합니다.

현장 방문 상담 시 운영 화면을 직접 보여드립니다.

FAQ

자주 묻는 질문

컴퓨터를 잘 몰라도 쓸 수 있나요?

메신저로 말하듯 요청하면 됩니다. 설치와 설정은 저희가 하고, 사용법은 현장 교육으로 알려드립니다.

얼마에요 같은 기존 프로그램을 쓰고 있어도 되나요?

기존 프로그램은 그대로 쓰셔도 되고, 현황판으로 대체하셔도 됩니다. 기존 데이터를 옮겨야 하는지는 현장 진단 때 확인해 안내드립니다.

윈도우 PC만 있는데 가능한가요?

가능합니다. 윈도우 환경이면 윈도우 미니PC로, 그 외에는 맥미니로 구성합니다. 기존 공유 폴더와 프린터도 연결합니다.

메일을 AI가 마음대로 보내지는 않나요?

거래처로 나가는 메일과 문서는 담당자가 확인 버튼을 눌러야 발송되도록 설정하는 것이 기본입니다. 자동 발송 범위는 업체가 정합니다.

회사 자료는 안전한가요?

에이전트는 업체 전용 PC와 전용 계정으로 따로 운영되며, 다른 업체와 섞이지 않습니다. 문서 작성 시 AI 서비스로 내용이 전송되는 구조와 보안 설정은 상담 때 자세히 설명드립니다.
